# APNA ROJGAR — USER ROLES

Apna Rojgar has three public user categories, plus an admin role used only by the team.

Primary audience: rural and semi-urban India, while also serving urban users.

Default consumer-facing language: simple Hindi and Hinglish. Use words people actually use in daily conversation.

## Worker

A person looking for work, including local, daily wage, contract, part-time, or full-time work.

Examples:

- मज़दूर
- मिस्त्री
- Carpenter
- Electrician
- Plumber
- Painter
- Welder
- Mechanic
- Driver
- Farm worker
- Agricultural worker
- Helper
- Housekeeping worker
- Security worker
- Delivery worker
- Factory worker
- Local workers

Use the word “मज़दूर” when appropriate for rural communication because it is familiar and relatable.

## Employer

A person, company, contractor, business, or organization that needs workers.

Examples:

- Homeowner
- Construction company
- Factory owner
- Farmer
- Shop owner
- Local business
- Service provider

## Mediator / Contractor

A person who coordinates workers or provides worker teams.

Stored role value: `MEDIATOR`.

In the app this person can build a team, send team requests, apply for work with those workers, and mark attendance.

## Admin

Stored role value: `ADMIN`.

Admin is for the Apna Rojgar team on the website admin area. It is not a role shown to workers or employers as a public signup choice.

Admin access comes only from the user role. A mobile number does not make someone an admin.

## Verification

Workers, employers, and mediators can be:

- Pending
- Applied
- Completed

Only `Completed` shows the verified tick beside the name. Pending and Applied users have no tick.

## Language to prefer

- काम
- रोजगार
- मजदूर
- कामगार
- काम देने वाला
- काम करने वाला
- ठेकेदार
- मौका
- जरूरत
- जुड़ें

Avoid unnecessarily technical or corporate vocabulary in consumer-facing communication.

## Role awareness

Always check whether a screen or message is for:

- Worker
- Employer
- Mediator / Contractor

Do not mix actions between roles.
